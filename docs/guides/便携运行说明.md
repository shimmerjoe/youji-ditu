# 便携运行与开发

仓库根目录就是完整项目，不需要进入嵌套的 `Travel_ayuan` 子目录。可以克隆到任意位置，工具按自身路径定位项目根目录。

## 安装与预览

在项目根目录运行：

```powershell
npm ci
python -m pip install -r requirements-build.txt
npm run preview
```

访问 <http://localhost:8765/>。Windows 也可以双击 `scripts/windows/打开首页.bat`；关闭服务器窗口即停止预览。完整搜索、模块脚本和离线缓存应通过 HTTP 检查。

## 修改与重建

- 城市正文：`城市/*.md`；综合内容：根目录 `记录.md`。
- 应用源码：`frontend/src/`；生成器与元数据：`tools/`。
- 图片与授权：`assets/photos/` 及对应来源 JSON。

```powershell
npm run check
npm run stage
```

`check` 构建 Vite、生成全站并执行类型检查、测试和站内校验；`stage` 生成可部署的 `dist/`。报告位于 `docs/reports/内容与图片体检.md`。

Windows 的重建、补图、手机预览和推送辅助脚本集中在 `scripts/windows/`。重复的打开入口已合并为 `打开首页.bat`。

## 提交与发布

审查 `git status` 和 `git diff`，选择性暂存、提交后再推送 `main`。发布脚本只推送已提交内容。源码上传不等于 GitHub Pages 上线；还需要相应托管权限、Pages 设置和成功的 Actions 部署。
